# V.A.U.L.T.
**Virtual Assistant for Universal & Local Tasks**

Cyberpunk/JARVIS temalı Agentic OS — Claude Code, Kimi K2 ve Gemini CLI için gerçek PTY terminal hub.

## Versiyonlar

| Versiyon | Durum | Açıklama |
|---|---|---|
| VAULT MARK X | Arşiv | İlk proje — tek seferlik subprocess terminal |
| VAULT MARK XI | Arşiv | Gerçek PTY terminal hub (pywinpty), 3 tab |
| VAULT MARK XII | **Aktif** | Terminal overflow fix + File upload routing |

## Başlatma

```
VAULT MARK XII\start.bat
```

Browser otomatik açılır → http://localhost:8765

## Özellikler
- Claude Code, Kimi K2.6, Gemini CLI — gerçek interaktif PTY terminaller
- Sistem monitörü (CPU/MEM/NET/GPU)
- Obsidian Memory entegrasyonu
- Dosya yükleme + AI'a yönlendirme
