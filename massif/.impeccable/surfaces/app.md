## Direction contract

THESIS: Disk mass is a core sample, not a ribbon office clone. The selected path is a vertical shaft; the table is the log; the treemap is the cut face.

OWN-WORLD: Basalt desk at night. Ground #12110f, panels #1c1a16, paper #ece6d8, dust #b7ae9c, copper #d4783a for measure and primary action. Segoe UI with tabular figures. Hairline copper rules, not cards.

STORY: Type or pick a path, scan, read which child owns the mass, export if needed.

FIRST VIEWPORT: Full-app chrome. Top measure bar (path + Scan). Main split: tree table dominant, treemap strip along the bottom of the current folder. Status line with totals and skipped errors. Empty state is the path field, not a hero.

FORM: Geological core log (assigned operate reconstruction; user demanded immediate production so the concept roll was skipped). Signature interaction: clicking a row rebases the treemap and breadcrumb shaft.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
